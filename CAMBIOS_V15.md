# V15 - Menú Seguridad

- Nuevo desplegable Seguridad: mantenimiento de usuarios, mantenimiento de perfiles y cambiar contraseña.
- Se eliminan enlaces duplicados a usuarios del menú principal.
- La nueva contraseña la define el usuario en el formulario, no se genera automáticamente ni se muestra después de guardarla.
- Contraseña inicial de una instalación nueva: Admin12345! (usuario admin). Cambiarla después del primer ingreso.
- Los perfiles financieros siguen siendo perfiles locales compartidos, no cuentas independientes de acceso.
