## Cómo reproducir y realizar la validación independiente

El procedimiento ejecutable está en el [README](../../README.md), secciones de requisitos, instalación, configuración, inicialización, pruebas y arranque. Otro integrante debe seguir **solamente ese README**, en una copia y base nuevas. Esta bitácora sirve para registrar sus resultados, sin suplir instrucciones que falten en el README.

El registro de validación deberá incluir:

1. Nombre del integrante, fecha, sistema operativo, versiones de Python y SQLite, y commit utilizado.
2. Confirmación de copia independiente y ruta de una base de ensayo nueva, sin publicar rutas privadas ni credenciales.
3. Comandos y salidas de inicialización WAL, conexión, carga de cinco movimientos y presupuestos del período, y resultado de la suite.
4. Arranque, inicio de sesión, selección del perfil y visualización de movimientos y presupuestos; capturas con datos inventados y sin contraseñas visibles.
5. Resultado final, dificultades y cualquier instrucción del README que necesitó ayuda externa. Corregir el README y repetir lo afectado si no se pudo seguir de forma autónoma.

**Estado de esa validación:** pendiente. No hay nombre, fecha de ejecución independiente, acta ni resultado para completar todavía. No confundir una copia independiente del repositorio con un verificador independiente.
