## Límites de seguridad

Se usa Python `http.server`, con sesiones en memoria, sin protección CSRF general de todos los formularios, sin rate limiting completo y sin gestor de reinicio persistente. La contraseña predeterminada de pruebas sigue permitida **solo** en localhost sin prefijo, nunca como credencial de una nueva instalación con prefijo. Proteger la base fuera de `public_html`; no usar datos financieros reales.
