## 5. Decisiones técnicas

1. Usar **SQLite como motor principal y único**: persistencia local reproducible y sin servidores adicionales. Este perfil exige profundizar en funcionalidades/mediciones del motor en los seguimientos posteriores.
2. Utilizar Python y su servidor HTTP integrado, sin Flask, Redis, MongoDB ni Docker para este MVP.
3. Trabajar inicialmente con una familia de demostración, montos CRC como enteros en céntimos, claves foráneas, índices y **WAL**.
4. Cargar únicamente datos ficticios; no usar información financiera o credenciales reales en el repositorio.
5. Priorizar estabilidad y pruebas antes de ampliar funcionalidad. Véase `docs/decisiones.md`.
